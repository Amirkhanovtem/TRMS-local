# ТЗ: Профиль руководителя

## Цель

Создать профиль руководителя, где он видит собственное обучение, прямых сотрудников, их обучение, сертификаты, заявки, feedback и отчеты.

## Пользователи

- Manager.
- Training Academy.
- Admin.

## Разделы

1. Мой профиль.
2. Мои сотрудники.
3. Запросы на обучение.
4. Feedback.
5. Дашборды.
6. Отчеты.

## Функциональные требования

### Мой профиль

- Повторяет подход Home сотрудника.
- Руководитель видит:
  - свои часы обучения;
  - сертификаты;
  - учебный путь;
  - рекомендации;
  - feedback.

### Мои сотрудники

- Показывать только прямое подчинение.
- Для каждого сотрудника:
  - ФИО;
  - позиция;
  - подразделение;
  - грейд;
  - прогресс обучения;
  - часы обучения;
  - сертификаты;
  - тренинги;
  - feedback status.
- При клике "Открыть профиль" открывается Home сотрудника в режиме manager view.

### Рекомендовать тренинг

- Руководитель может рекомендовать тренинг сотруднику.
- Тренинг выбирается из справочника training templates.
- Рекомендация появляется в профиле сотрудника.
- Сотрудник получает notification.

### Зачислить сотрудника

- Руководитель может зачислить сотрудника на доступный тренинг.
- Система должна проверить:
  - доступность сессии;
  - свободные места;
  - конфликты по расписанию;
  - prerequisites.
- После зачисления создается participation card.

### Запросы на обучение

- Руководитель создает заявку в Training Academy.
- Статусы заявки видны руководителю.
- Есть чат по заявке.
- При завершении планирования руководитель видит итог:
  - события созданы;
  - даты;
  - группы;
  - аудитории;
  - тренеры.

### Feedback

- Руководитель видит feedback по своей команде.
- Показатели:
  - pending feedback;
  - completed feedback;
  - completion rate;
  - NPS;
  - средняя оценка;
  - последние комментарии.

## Данные

- Person hierarchy.
- Training history.
- Certificate issue.
- Participation cards.
- Learning requests.
- Feedback assignments.
- Feedback responses.

## Права доступа

- Manager видит только своих прямых сотрудников.
- Training Academy может видеть заявки и агрегированные данные.
- Admin видит все.

## API

- GET manager profile.
- GET manager direct reports.
- GET employee details for manager.
- POST recommend training.
- POST enroll employee.
- GET manager learning requests.
- GET manager team feedback.

## Acceptance criteria

- Руководитель видит только своих сотрудников.
- Рекомендация тренинга появляется у сотрудника.
- Зачисление создает реальную запись участия.
- Заявки синхронизируются с разделом Training Academy.
- Feedback по команде строится по реальным ответам.
