# ТЗ: Rewards and Forum

## Цель

Добавить в профиль сотрудника элементы мотивации и внутреннего сообщества: Reward Shop, бейджи, ачивки, персональную витрину и форум сотрудников.

## Пользователи

- Employee.
- Manager.
- Training Academy.
- Admin.

## Rewards

### Раздел "Мои награды"

Показывать:

- покупки в Reward Shop;
- бейджи;
- ачивки;
- reward points;
- персональный баннер;
- кастомное поле профиля.

### Reward Shop purchases

Поля:

- reward id;
- title;
- cost;
- purchase date;
- status;
- expiry date;
- source.

Статусы:

- active;
- received;
- used;
- expired.

### Badges and achievements

Источники:

- завершение учебного плана;
- прохождение обязательных тренингов;
- активность в форуме;
- заполнение feedback;
- отсутствие просроченных сертификатов.

## Profile showcase settings

Сотрудник может настроить:

- баннер профиля;
- кастомное поле;
- видимость некоторых наград.

Admin должен иметь возможность отключить кастомизацию при необходимости.

## Forum

Раздел форума должен поддерживать:

- создание темы;
- ответы;
- лайки;
- топ 3 обсуждаемых темы;
- FAQ по обучению;
- поиск;
- категории;
- закрепленные темы.

Топ 3 обсуждений показывать как пьедестал:

- 1 место;
- 2 место;
- 3 место.

## Модерация

Training Academy или Admin может:

- закрыть тему;
- закрепить тему;
- удалить некорректный ответ;
- отметить лучший ответ;
- перенести тему в FAQ.

## API

- GET rewards.
- GET employee rewards.
- POST reward purchase.
- PATCH reward status.
- GET badges.
- GET forum topics.
- POST forum topic.
- POST forum reply.
- POST forum like.
- PATCH forum moderation status.

## Acceptance criteria

- Сотрудник видит свои награды и бейджи.
- Покупки Reward Shop отображаются в профиле.
- Форум позволяет создать тему и поставить лайк.
- Топ 3 обсуждений строится по активности.
- Модератор может управлять темами.
