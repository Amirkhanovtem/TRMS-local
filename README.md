# TRMS (Front)

Version: 5.0.0

This project was generated with [Angular CLI](https://github.com/angular/angular-cli) version 15.0.4.

## Development server

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The application will automatically reload if you change any of the source files.

## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.

## Structure

Config file is located in `app/config/config.ts`. This file contains common urls and properties.

For working with environment system properties, used [Ngx-Env](https://github.com/chihab/ngx-env) library.
The main file of settings is located in `env.d.ts` in root of project.

For localization, system using class `app/localization/localization.ts`.

The main angular-module of [Angular Material](https://material.angular.io/) is located in `app/material/material.moduel.ts`.

## Пояснительная записка

В рамках первого релиза выполнены следующие разделы:

- Справочники.
- Календарь.
- Создание/редактирование события на календаре.
- Заполнение листа участия, результатов экзамена, формирование сертификата и выгрузка сертификата.
- Проведенные тренинги.
- Личный кабинет.
- Локализация на рус. и англ.языке.

Раздел “Справочники” - это образующая часть системы, от которой зависят другие формы.

Переход в раздел “справочники” происходит с навигационного меню.

Для выбора определенного справочника кликаем на “Название из списка”.

В справочниках реализован “поиск по значению, сортировка”, “переключение на отображение по 5, 10, 20” строк, “пагинация”.

**Порядок заполнения справочников:**

- Расположение.
- Аудитории.
- Категория Тренинга.
- Тип тренинга.
- Экзамены.
- Сертификаты.
- Пользователи.
- Тренеры.
- Тренинги (модули в них).
- Учебные планы.

**Доступно “создание/изменение/удаление строки справочника:**

- “Создание строки” - нажать “создать” - вписать значения в поля - нажать “создать”. При необходимости можно закрыть форму. Тогда строка не создастся.
- “Изменение строки” - выбрать созданную строку - нажать “изменить” - изменить значения в полях - нажать “сохранить” .
- “Удаление строки” - выбрать созданную строку - нажать “удалить” - в модальном окне удаления нажать “подтвердить”. При необходимости можно закрыть модальное окно. Тогда строка не удалится.

**Валидация, при незаполнении полей/некорректном заполнении:**

- Строка не создается/не сохраняется, если не заполнены обязательные поля. Незаполненные обязательные поля подчеркиваются красным. Отображается надпись "Поле дб заполнено".
- Строка не создается/не сохраняется, если в справочнике поле "код" заполнено неуникальным значением. Незаполненные корректно поля подчеркиваются красным. Отображается надпись "Поле дб уникальным".

**2. Отображение и функционал календаря:**

- В календаре отображаюися данные из созданных справочников “Аудитории, Оборудование, Тренеры (только основные).
- Одна плашка = 1 день.
- Присутвует переключатель “отображение черновиков”/"Отображение событий".
- Доступно сворачивание и разворачивание разделов.
- Отображаются подсказки, при наведении мыши на ресурс или событие.
- При двойном клике на ресурс отображается информация о нем.
- Одно событие выделено одним цветом в каждом разделе.

**3. Создание/редактирование события**
Открыть форму создания события можно двумя способами:

- Зафиксироваться на плашке - нажать “создать”.
- Выбрать плашку - кликнуть 2 раза.

Открыть форму редактирования события:

- Выбрать плашку - кликнуть 2 раза.

Создание/редактирование события - “Тренинг/УП”

- Выбирать дату - нажать на кнопку “создать событие”/ Выбрать плашку - кликнуть 2 раза.
- Открывается форма выбора тренинга или УП - выбирается тернинг/УП.
- Далее событие заполняется ресурсами. Заполненные ресурсы прокидываются от высшего звена иерархии, но редактируемы.
- Событие сохраняется только, если заполнены обязательные поля.
- Событие сохраняется как черновик, если заполнено одно из обязательных полей.
- Все проверки происходят по кнопкам "сохранить", "закрыть" и "сохранить как черновик".
- Событие можно сохранить из черновик в запланированное и наоборот.

**4. Лист участия, результаты экзамена, формирование и выгрузка сертификата**

- Выбрать завершенное событие-тренинг - кликнуть 2 раза.
- Нажать на кнопку "Лист участия" - заполнить посещение - заполнить статус - нажать подтвердить - добавить результаты экзамена - сформировать сертификат - выгрузить.
- Тренинг может не предполагать сертификат либо быть безэкзаменационным. В таком случает только подтвержается присутствие.
- Кнопка "сформировтаь сертификат" неактивна пока не заполнен проходной балл по экзамену/подтверждено участие (если нет экзамена).
- Добавление экзаменов недоступно пока не подтверждено участие.

**5. Форма "Проведенные тренинги"**

- переход через навигационное меню.
- в форме отображаются все тренинги в стаусе "Завершен".
- при клике 2 раза на форму - осуществляется переход на лист участия.

**6. Личный кабинет**

- переход через навигационное меню.
- форма не редактируется. Можно просмотреть краткую и подробную информацию.

**7. Локализация**

- на форме авторизации отображается значок выбора языка.
- при выборе определенного языка - вся система отображается на нем.

**8. Доступность по ролям**

- admin - доступны все формы для создания, редактирования и просмотра.
- planer - доступны ЛК, форма просмотра всех строк в справочнкиах, создание события, редактирования события, автором которого он является, просмотр события других планеров-авторов,админа; отображение и редактирование черновиков, автором которых он является.
- user - доступны ЛК, события на календаре.
- trainer - доступны ЛК, события на календаре, форма "Список проведенных тренингов".
